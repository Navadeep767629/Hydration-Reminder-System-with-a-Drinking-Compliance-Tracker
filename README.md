<h3 id="project1">Project 1: Hydration Reminder System with a Drinking Compliance Tracker</h3>
<p>
 The Hydration Reminder System with a Drinking Compliance Tracker is an IoT-based solution designed to help users maintain healthy hydration habits. It uses an ESP32 and an external copper-strip capacitive sensor to monitor the water level and calculate water consumption in real time. The system displays hydration information on an OLED screen and sends reminders and status updates through Telegram. It also tracks sip count, daily hydration goals, and progress, making water intake monitoring simple, accurate, and user-friendly.
